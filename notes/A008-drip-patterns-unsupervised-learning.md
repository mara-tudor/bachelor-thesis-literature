# A008 — Unsupervised machine learning for the detection and interpretation of key features in drip patterns

**Authors:** Stanard M. Pachong; Ainaz Alavi; Shaijieni Kannan; Theresa Stotesbury; Peter R. Lewis  
**Year:** 2026  
**Area:** Bloodstain pattern analysis (BPA)  
**Reference:** https://pubmed.ncbi.nlm.nih.gov/41033067/  
**Reading status:** Abstract reviewed  
**Priority:** H


## Research question / objective

Identify measurable features distinguishing laboratory-generated blood drip patterns.

## Method and algorithms

Unsupervised machine learning, image-derived stain features, SHAP feature importance.

## Dataset and data availability

398 lab-generated patterns; drip heights 25-100 cm and 1-10 droplets.

## Evaluation measures

SHAP-based feature contributions; unsupervised analysis.

## Main findings

Circularity, mean intensity, and parent-stain area were key features (reported contributions 60%, 28%, 28%, respectively).

## Limitations or points to verify

Laboratory drip patterns; generalization to complex crime-scene patterns has not been shown by this abstract.

## Relevance to my thesis

Highly relevant to explainable feature extraction and objective BPA classification.
